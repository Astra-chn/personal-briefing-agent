### 1. TokenBar：多模型 AI 配额监控工具
- 链接：https://github.com/lwh0630/TokenBar
- 是什么：开源、跨平台 AI 配额监控工具，支持 Codex、Claude、Cursor 及另外 47 个服务，覆盖 Windows、macOS、Linux、Android、iOS，使用 Flutter/Dart，208 Stars。
- 为什么值得看：你关注多种 AI 工具和自动化，配额分散管理是实际问题。
- 对你：**适合当工具用，不适合作为后端转 AI 的主线源码项目**。Flutter/Dart 不是你的优先技术栈，先花 30 分钟试用或看 README 即可。

### 2. WebsiteBench：AI Agent 能否通过浏览器探索重建网站
- 链接：https://github.com/TIGER-AI-Lab/WebsiteBench
- 是什么：一个 Python 项目，研究 AI Agent 是否能通过浏览器探索来重建网站，177 Stars。
- 为什么值得看：Agent 评测正在从“问答”走向“真实网页操作”，这比只看 Agent 框架更接近能力边界。
- 对你：**适合了解 Agent 评测思路，不适合作为第一个动手项目**。你需要先有 Python 和浏览器自动化基础；现在先读任务定义和成功标准即可。

### 3. CodeRabbit：AI 代码治理与交付案例

- 为什么值得看：这说明 AI 编程正在从“代码补全”进入代码审查、流程治理和交付环节。
