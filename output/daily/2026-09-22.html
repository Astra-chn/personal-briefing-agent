一、今日最值得关注的 5 件事

1. 特朗普—习近平会晤，美国大科技公司高层集体出席

  • 来源：newspim.com
  • 是什么：韩媒报道称，在特朗普与习近平的晚宴上，美国大型科技公司高层"总出动"，各方围绕中国市场的算盘很复杂。
  • 为什么重要：科技公司高层出现在首脑会晤场合，通常意味着市场准入、出口管制这类议题被摆上桌面——也就是"公司利益"和"国家博弈"在同一张桌子上谈。
  • 对你有什么用：如果你关注 AI/半导体行业的就业和岗位方向，这类会晤的结果会间接影响招聘结构（哪些方向扩、哪些缩）。但现在只有标题，不要据此下判断，等正式通稿。

2. 中美 AI 谈判前夜：三星/SK海力士的位置，与中国存储芯片的追赶

  • 来源：etoday.co.kr
  • 是什么：标题大意是"中美 AI 谈判前的三星·海力士……中国内存追赶成为反弹变量"。三星和 SK 海力士是韩国两大存储芯片厂，标题把它们放在了中美 AI 谈判的语境里。
  • 为什么重要：存储芯片（HBM、DRAM）是 AI 算力的上游。中美谈判的风向会直接影响存储芯片的供需、价格和产能布局。
  • 对你有什么用：这是"国际形势 → 科技产业 → 就业"的一条链。如果你想进硬件/AI 基础设施方向，存储和算力供应链是需要长期跟踪的基本盘。但具体谈判条件、中国追赶到什么程度，标题里没说，不要在群里转发未经证实的细节。

3. 中东局势被放在同一时间窗口讨论

  • 来源：newstomato.com
  • 是什么：标题称特朗普—习近平会谈，中东也是"分水岭"。
  • 为什么重要：如果中东议题和中美议题同期被讨论，说明这是多条线同时博弈的窗口期。中东关系到能源价格，能源价格关系到全球通胀和货币政策。
  • 对你有什么用：判断科技行业融资环境、就业市场松紧时，宏观利率是个背景变量，而能源是它的输入之一。同样：只有标题，不能推断具体内容。

4. OpenAI 发布 V7：把公司散落的文件变成 Agent 能用的"机构记忆"

  • 来源：openai.com/index/v7
  • 是什么：据摘要，V7 使用 GPT-5.6，把公司里分散的文件转成 Agent 可用的上下文，用来完成复杂的、带来源链接的工作。
  • 为什么重要：这是企业 RAG 从"检索几个片段"升级到"上下文层/机构记忆"的信号，而且特别强调 source-linked（可溯源）。
  • 对你有什么用：这条和你方向最相关。它说明 RAG 的竞争力不只在向量检索，还在于：上下文怎么组织、引用怎么回溯。做简历项目时，把"引用溯源"做出来，比堆一个向量库更能体现水平。

5. GitHub：aitracker——本地优先的 AI 用量追踪 + 会话沉淀

  • 来源：github.com/estelwalks/aitracker
  • 是什么：开源、本地优先的 AI 工作台，统计 Claude Code、Codex、Cursor 等工具的 Token 用量和花费，并把每次会话沉淀为可复用的 Skills 和长期记忆。TypeScript，94 stars / 15 forks。
  • 为什么重要：它把两件对你的学习最有用的事合在一起——成本可视化和记忆沉淀。后者正是 RAG / Agent 记忆主题的工程化落地。
  • 对你有什么用：见下面 GitHub 章节的详细评估。

二、GitHub 热门项目（按是否适合你排序）

⭐ 推荐先看：estelwalks/aitracker

🔗 https://github.com/estelwalks/aitracker - TypeScript | 94 stars | 15 forks

适不适合你：适合，本期最推荐。 理由： - TypeScript 对初学者比纯 JavaScript 友好，类型提示能帮你读懂数据结构。 - 主题正中你的关注点：AI 工具链 + 记忆沉淀 + RAG 相关。 - 有 15 个 fork，说明有人真的在改它，不是纯展示项目。

怎么用它学习（两步走）： 1. 先当用户：跑起来，看它怎么读 Claude Code / Cursor 的本地数据。这一步能让你理解"AI 工具的数据存在哪"。 2. 再当读者：只挑一个模块读，比如"一次会话怎么变成 Skill"。不要试图通读全部代码，会劝退。

🔧 概念价值高，但读代码偏难：Xu123-Bob/Baize（白泽）

🔗 https://github.com/Xu123-Bob/Baize - JavaScript | 72 stars | 1 fork

是什么：开源 AI Coding Agent CLI，支持多后端（DeepSeek / OpenAI 兼容 / Ollama 本地），有工具调用、技能加载、子代理委派、上下文压缩、安全沙箱。

适不适合你：适合"用"，不太适合"读全部"。 它是一个 Agent 的完整骨架，功能列得很全，但 72 stars / 1 fork 说明几乎没人参与，且 JS 项目结构通常比 TS 难跟。

建议：接一个本地 Ollama 跑通它，然后只看两个点： - 工具调用（tool calling）怎么定义和分发——这是所有 Agent 的核心。 - 上下文压缩怎么做的——这直接关系到长对话和 RAG。

风险提示：单作者早期项目，别拿它跑重要代码，沙箱能力未经第三方验证。

⏸️ 建议观望：s88cj-stack/Lithicsoft-Trainer-Forge

🔗 https://github.com/s88cj-stack/Lithicsoft-Trainer-Forge - HTML | 55 stars | 0 forks

适不适合你：本期不建议投入时间。 材料里只有一句"Professional Trainer Studio Generator Suite 2026 – Open Source AI Coaching Toolkit"，语言标注是 HTML，0 fork。信息太少，看不出技术含量，也没有社区验证。收藏一下，等下期有新信息再说。
