## 一、今日最值得关注的 5 件事

**1. 特朗普签署对俄制裁法案，关税威胁直接点名中国和印度**
- 材料事实：新法允许对俄罗斯石油的主要买家征收最高 100% 的关税，包括中国和印度。
- 为什么重要：这不是单纯的美俄问题，而是把「买俄油」变成对第三国的贸易施压工具。中国被直接点名，意味着能源进口成本、外贸环境、相关企业利润都可能被牵动。
- 对科技/就业的关系：能源和外贸成本上升，会先传导到制造业、物流、外贸岗位。**但材料没有给出任何具体影响数据，我无法判断幅度**，只能说这是需要持续跟踪的变量，不是已经落地的既成事实。
- 链接：https://www.aljazeera.com/news/2026/9/19/trump-signs-sweeping-russia-sanctions-over-ukraine-war

**2. 日本央行加息到 1.25%，31 年新高**
- 材料事实：从 1% 上调至 1.25%，为 1995 年以来最高；报道称此举是为了应对与伊朗战争相关的全球通胀；文中提到这是跟随美联储、欧洲央行的紧缩方向。
- 为什么重要：全球主要经济体利率同步走高，意味着**全球资金变贵**。对初创公司和科技行业来说，融资环境通常会更紧——这是我的判断，材料本身只讲了利率和通胀。
- 和你的关系：如果你有留学、换汇、海外消费或理财计划，这类消息比大多数 AI 新闻更直接影响你的钱包。
- 链接：https://www.theguardian.com/business/2026/sep/18/japan-raises-interest-rates-to-31-year-high-rising-prices

**3. 韩国总统李在明明确拒绝为美国对伊朗战争派兵**
- 材料事实：李在明在记者会上说「不会有涉及或进入战争的部署」，拒绝特朗普要求其支持对伊朗战争；此前外界猜测韩国可能向霍尔木兹海峡派兵。
- 为什么重要：这是美国盟友体系内部的一次公开分歧。霍尔木兹海峡直接关系全球石油运输，这条和上面第 1、2 条是同一个链条：地缘冲突 → 油价 → 通胀 → 加息。
- 对你的关系：能源价格和全球通胀预期，会间接影响国内物价和就业环境。材料没有给出海峡通行或油价的具体数据，不展开推测。
- 链接：https://www.theguardian.com/world/2026/sep/18/south-korea-will-not-send-military-to-support-us-war-on-iran-defying-trump-pressure

**4. OpenAI 发布 GPT-6 Astra（注意：这是 9 月 9 日的消息）**
- 材料事实：OpenAI 称其为面向商业场景的最强模型，强调高级推理、computer use（计算机操作）、更强的写作和设计判断力。

## 二、GitHub 热门项目（本期两个，均不是 RAG/Agent 方向）

**1. lakeday-org/perch —「Semantic code linting with Jev」**
- 链接：https://github.com/lakeday-org/perch
- 数据：Stars 73 / Forks 2 / 语言 JavaScript
- 是否适合你：**不太适合作为你的主学习项目**。理由：① 73 星属于小众早期项目，文档和社区支持通常很薄，新手卡住没人问；② 语义级代码检查（linting）需要一定的编译器/AST 基础，你目前代码基础不强；③ 它和你的目标方向（AI Agent、RAG、自动化工具）没有直接关系。
- 可以用它做什么：如果你想理解「代码检查工具是怎么工作的」，可以只读 README 和主入口文件，看看它的输入输出是什么。别指望靠它入门。

**2. princechhimpachhimpasaab-lang/omega-epsilon-problem-forge — 数学奥赛题生成器**
- 链接：https://github.com/princechhimpachhimpasaab-lang/omega-epsilon-problem-forge
- 数据：Stars 55 / Forks 0 / 语言 HTML
- 是否适合你：**相对更适合，但仍要降低预期**。理由：① 语言标注是 HTML，说明主体很可能是简单的前端页面，代码量小、结构简单，适合初学者看懂全貌；② 「无限生成题目」这类项目的核心逻辑通常是「模板 + 随机参数 + 输出」，这个套路你在做自动化工具时会反复用到；③ Forks 为 0，说明几乎没有人跟进，别把它当成有社区背书的热门项目。
- 可以怎么学：克隆下来，试着改一个题目模板，或者把它换成中文题目、换成行测/常识题生成器——这和你的公考关注点能结合上，而且是完整的小项目闭环。

**结论：本期没有命中 RAG 或 AI Agent 方向的仓库。** 不要为了凑数把它们包装成「AI 前沿项目」。
