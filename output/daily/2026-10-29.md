### 1. 港交所推出 AI 与半导体指数

## 二、GitHub 热门项目（按对你的学习价值排序）

### ① RabbittuX/purrge —— 最推荐你读
[链接](https://github.com/RabbittuX/purrge)｜Python｜101 stars / 16 forks
macOS AI 磁盘清理：空间不足时提醒，AI 逐项判断哪些能清，**你勾选确认后才执行**。
**为什么适合你**：Python 代码量小、逻辑清晰，而且是典型的“AI 给建议 + 人做决策 + 程序执行”的**审批流**模式——这正是企业级 Agent 最难也最值钱的部分。**限制**：仅 macOS；如果你不是 Mac，可把“扫描文件”换成任意 mock 数据，只跑 AI 判断 + 确认 + 执行这三段，仍能学到核心思路。

### ② jaisurya-dev-art/rigby2d —— 只挑 MCP 部分看
[链接](https://github.com/jaisurya-dev-art/rigby2d)｜JavaScript / Rust / Godot｜69 stars
2D 骨骼动画编辑器：PSD 自动绑定、网格/IK/物理动画、音频口型同步、导出 JSON/.skel，**内置给 AI 助手用的 MCP server**。
**为什么适合你**：整个项目不适合初学者通读（图形数学 + 三套运行时 + 引擎集成，劝退）。但它**内置的 MCP server 部分**是当下最值得学的接口形态：怎么把一堆工具函数暴露给 AI 助手。建议只定位到 MCP 目录，看工具定义和参数校验，别碰渲染核心。**注意**：69 stars，属于小项目，文档在 GitHub Pages，别指望有成熟生态。

### ③ guolola/SoftJL —— 学“结构化输出”，不学全栈
[链接](https://github.com/guolola/SoftJL)｜TypeScript｜121 stars / 5 forks
需求 → UML 图 / 测试用例 / 可编辑 Word 规格，带可追溯性；自托管，自带 AI 模型；明确面向毕设和课程项目。
**为什么适合你**：它把“一段自然语言需求”转成“几种固定结构的交付物”，这是 RAG 和 Agent 里最实用的能力（结构化输出 + 可追溯）。**限制**：全栈 TS + UML 生成 + Word 导出 + 模型接入，代码面较宽，读全量会累。建议只看它的 prompt / schema 定义部分。

### ④ Limatura/tessera —— 不建议当学习项目
[链接](https://github.com/Limatura/tessera)｜Rust｜71 stars
自托管文件与笔记分享，会“自我清理”。
**为什么不推荐**：Rust 对初学者门槛高，且它是工具型项目，架构上没有特别值得你借鉴的 Agent / RAG 结构。功能设计（自动过期清理）可以看两眼，代码不必读。

## 三、AI 发展动态

**三个方向，本期都在同一批材料里：**

1. **Agent 进入垂直工作流，而不是停留在通用助手。** ServiceNow（IT 服务管理）和 Legora（[法律工作](https://openai.com/index/legora)，合同分析、用 ChatGPT/Codex 加速律师工作流）都是“流程固定、结果可校验、出错可回滚”的领域。趋势判断：Agent 的商业价值正集中在**有明确 SOP 的行业**，通用闲聊型产品的空间在压缩。

2. **入口之争：ChatGPT / Codex 正在变成“工作台”。** ServiceNow 这条里，工作流被反向接进 ChatGPT 和 Codex，说明模型厂商在抢“你每天打开的第一个界面”。对你的启示：以后做 AI 产品，要考虑自己是“被嵌进去”还是“嵌别人”。

3. **安全开始工程化、公开化。** OpenAI 讲隔离环境和高算力红队，是从“表态”转向“披露机制”。这意味着**AI 安全/合规类工程岗位**会继续增加。
