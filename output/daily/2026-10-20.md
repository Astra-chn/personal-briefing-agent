## 一、今日最值得关注的 5 件事

### 1. AI Agent 的“安全沙箱”开始成为独立基础设施
[strands-agents/box](https://github.com/strands-agents/box)｜GitHub｜2026-10-20｜445 stars / 27 forks / Rust

它的做法是：把 Agent 关进沙箱，限制它能执行什么、读写什么、能连哪些网络地址；默认拒绝（Dogwood 策略）；凭据由外部注入，密钥不进入 Agent 进程。目前只支持 Apple 芯片的 macOS，Linux 在计划中。

**为什么重要**：Agent 从“能跑起来”进入“敢让它跑”的阶段。企业不敢让 Agent 直接操作文件系统和网络，就是这个原因。凭据外置和默认拒绝，是落地时的硬性条件。
**对你的用处**：你现在不写 Agent 生产系统，但“最小权限 + 密钥不进代码”这两个概念，是你以后做任何后端或 AI 应用都要用的。这条属于**思路值得学、代码暂时不用碰**。

### 2. OpenAI 在补“低资源编程语言”的编码能力
[Advancing coding in low-resource programming languages](https://openai.com/index/low-resource-programming-languages)｜openai.com｜2026-10-19

材料提到新增了软件工程、SQLite 和 **COBOL 迁移**方面的评估。

**趋势影响**：AI 编码助手正从 Python/JS 这类热门语言，往**企业存量老系统**扩张。COBOL 出现在评估里，指向的是银行、保险、政府系统的现代化改造。
**对你的用处**：这是“后端转 AI”最现实的落地方向之一——不是去做模型，而是做**老系统 + AI 辅助迁移**这类工程活。这类岗位看重的是你懂业务系统，与算法能力关系不大。

## 三、AI 发展动态

三条新闻放在一起看，指向同一个方向：**AI 正在从“通用能力展示”转向“进入具体工作流”**。

1. **语言维度**：往低资源语言、遗留系统铺（COBOL、SQLite 评估）。
2. **组织维度**：往企业知识库接（Atlassian 合作）。
3. **专业维度**：往垂直专业服务走——[Sullivan & Cromwell 用 OpenAI 做合同协议审查工具](https://openai.com/index/sullivan-cromwell)（2026-10-15，非当日），做的是识别草案协议中的问题。

**对你的判断依据**：这三条都不是“模型变强了”，而是“模型被放进具体流程了”。这意味着**懂流程的人比懂模型的人更稀缺**。你后端出身、正在学 AI，优势在流程这一侧，不在模型那一侧——不要花大量时间去啃训练和微调。

**但要克制**：这些是厂商自己发布的合作公告，天然带宣传色彩，实际效果没有第三方验证。别把它们当成“RAG 已经成熟”的证据。
