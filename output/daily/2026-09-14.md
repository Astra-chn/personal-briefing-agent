### 2. OpenAI 终止向 Cursor 提供模型，原因是 Cursor 被 SpaceX 收购
- 来源：[openai.com](https://openai.com/index/our-decision-on-cursor-following-its-acquisition-by-spacex)
- **是什么**：OpenAI 决定终止向 Cursor 提供 OpenAI 模型的合同，背景是 Cursor 被 SpaceX 收购。
- **为什么重要**：AI 编程工具和模型供应商之间的关系，会受资本并购影响。开发者常用的工具，底层模型供应可能突然变化。
- **对你有什么用**：如果你以后做 AI Agent 或后端转 AI，尽量不要把系统绑死在单一模型/单一供应商上。多后端抽象、可替换模型，是更稳的设计。GitHub 项目 Baize 就强调支持 DeepSeek / OpenAI 兼容 / Ollama 本地，这个思路值得学。

### 3. OpenAI 扩大对新闻业的支持
- 来源：[openai.com](https://openai.com/index/supporting-journalism-from-classrooms-to-newsrooms)
- **是什么**：OpenAI 面向学生、教育者、记者和新闻机构，扩大工具、培训和合作。
- **趋势影响**：AI 公司与内容行业的关系，正在从“版权冲突”转向“合作、培训、工具支持”。这对做 RAG 的人有直接影响：新闻/媒体语料的授权、溯源、合规会越来越重要。
- **对你有什么用**：如果你做 RAG 项目，别只抓网页文本。要开始习惯记录来源、授权状态、发布时间和可追溯链接。

### 4. 开源 AI Coding Agent CLI：Baize（白泽）
- 来源：[github.com/Xu123-Bob/Baize](https://github.com/Xu123-Bob/Baize)
- **是什么**：JavaScript 写的 AI 编程 Agent CLI，支持多后端，具备工具调用、技能加载、子代理委派、上下文压缩、安全沙箱。
- **为什么值得关注**：它把 AI Coding Agent 的关键模块都摆出来了，适合理解 Agent 架构，而不只是“用聊天写代码”。
- **是否适合你**：适合你作为项目学习素材，但**不建议一上来读全部源码**。先跑通、看 README、看命令入口，再挑“工具调用”或“上下文压缩”一个点读。
